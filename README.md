# Easy Clipper

A fast, lightweight, portable video clip editor for Windows — trim, split, stitch and export clips to MP4, GIF or audio.

Built with [Tauri](https://tauri.app), Svelte and FFmpeg.

## Development

Requires Node.js, Rust and FFmpeg on `PATH`.

```bash
npm install
npm run tauri dev
```

Tests: `npm test` and `cargo test --manifest-path src-tauri/Cargo.toml`.
